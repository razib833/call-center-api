# Contract generation

Builds use committed generated C# and need no SQL connection, Node.js or ScriptDom. To regenerate after reviewing SQL source changes: update the source inventory in Database/06_Tests/ProcedureContracts.json as needed, run ExtractResults.ps1 with the installed Microsoft ScriptDom DLL (C360_SCRIPTDOM_DLL override), then run node GenerateContracts.cjs. Run from this tools directory in a full Customer360 checkout; Database is its sibling through the Api parent. The export ignores the SQLCMD deploy wrapper. Rerun both steps after SELECT changes; the saved probe snapshot alone is not proof that changed source still matches. Review generated diffs, rebuild, rerun all applicable tests and export OpenAPI again. Generation never connects to SQL or executes deployment.
